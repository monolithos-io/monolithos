# MonolithOS

**One phone. Two worlds.**

[![MonolithOS on a Pixel, with separate Public and Work environments](https://monolithos.io/og/en.png?v=4)](https://monolithos.io/)

MonolithOS is an independent, privacy-focused operating system based on GrapheneOS. It gives everyday life and professional work separate environments on one phone, each with its own apps, accounts, and local files.

| Environment | What belongs there |
| --- | --- |
| **Public** | Everyday calls, messages, personal accounts, and familiar apps. |
| **Work** | Client documents, professional accounts, and the apps you use to get work done. Work has its own unlock credential. |

## How the separation works

Public and Work are separate Android users with their own app data and credential-encrypted storage. They share the phone’s hardware and operating system. Once Work has successfully closed, its apps stop and its credential-encrypted storage is locked again. You can continue using Public while Work remains closed.

The system builds on GrapheneOS hardening and uses Monolith Updater to deliver signed MonolithOS releases. The security architecture guide explains what comes from Android and GrapheneOS, what MonolithOS adds, and where the protection boundaries are.
